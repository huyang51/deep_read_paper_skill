# 速览卡模板（quick 档产出——对应 Keshav 第一遍"5-10 分钟判断值不值得读"）

> quick 档只做本卡：不建完整报告、不提取嵌图、不做 11 维分析。
> 存放：`<vault_dir>/reports/{short_name}_速览卡.md`；记忆条目仍建（read_mode: quick）。

```markdown
---
title: "论文标题（原文）"

year: YYYY
venue: "会议/期刊/arXiv"
read_mode: quick
date_read: YYYY-MM-DD
---

# {short_name} 速览卡

**30 秒定位**：[谁、在什么任务上、用一句话思路、取得一句话效果]

## 5C 判读卡

| C | 内容 | 初判 |
|---|------|------|
| **Category** | 论文类型（方法/基准/系统/理论/综述/报告） | [一句话] |
| **Context** | 属于哪条问题线，什么阶段 | [一句话，不确定的外部断言标【未核验】] |
| **Correctness** | 声称的核心证据是什么（哪个表/图支撑主张） | [一句话；明显薄弱点标 ⚠️] |
| **Contributions** | 最实质的 1-2 个贡献（是"新"还是"大"？） | [一句话] |
| **Clarity** | 好不好读，图/表/写作质量 | [一句话] |

## 关键数字（最多 3 个）

- [指标] [值]，对比基线 [名] [值] —— 提升 [幅度]

## 决策建议

- **建议档位**：[速览到此为止 / 升级 standard 精读 / 升级 deep 深读]
- **理由**：[与当前研究线的关系；判据见 SKILL Phase 0 分诊表]
- **升级成本预估**：[约 X 页正文 + Y 页附录]

## 与知识库的连接（若库非空）

- 相似已读：[[paper A]]（同方法线）/ [[paper B]]（同数据集）
- 待读推荐：[1-2 篇，标读/未读；仅凭本页判断，不做外部检索]

> 本卡基于标题/摘要/引言贡献段/结论/图表清单的浅读（未逐页全文），
> 所有外部事实断言未经 cite_verify 核验，仅作分流参考。升级精读后以完整报告为准。
```
